# Numbered header and footer follow-up

Wordcraft measures section decorations before body pagination and paints headers and footers after the body has consumed its list numbers. Its footer performs an additional measurement before painting. EdgeDoc now preserves these counter effects, uses distinct paths for story paragraphs, and applies table alignment and compatibility indents to tables in decoration bands.

The four targeted cases in `header-numbering-followup-result.json` pass the strict glyph and raster comparison: numbered one- and two-page header tables, a two-page numbered header paragraph, and a two-page numbered footer paragraph. The header-table first page and footer second page were visually inspected in both renderers; the former has identical PNG hashes. A numbered header spanning two sections also passed. Three original DOCX inputs are retained in `crates/edgedoc-display/tests/fixtures/numbered-stories`, with an end-to-end label regression test.

The 40-case header, footer and section regression run in `header-story-regressions-result.json` records 27 passes and 13 existing failures; the numbered header-table fixture improved from failure to pass and the other 39 cases kept their previous status. This does not establish general DOCX parity: the preceding 390-case run still records 199 failures and 18 blocked cases after retrying one timeout.

The subsequent 394-case run hit a transient disk-full error; its original report is retained as `header-394-parity-result.json`. All 64 newly blocked cases were rerun or re-compared after recovering space. The separate results are linked from `header-394-combined-status.json`: together they yield 178 passes, 198 failures and 18 blocked. The four new numbered-story fixtures pass, the previously failing single-page numbered header table now passes, and the ligature case blocked by a timeout in the preceding run passes. Every other prior case retains its baseline status. The largest file was compared page by page while discarding reproducible raster caches to bound disk use.
