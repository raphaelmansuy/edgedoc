# Inline pictures and text

Inline pictures embedded in a paragraph now participate in line width, ascent and baseline calculations, and paint at their marker position rather than being placed after the paragraph. Their effect extents contribute to the line box and are preserved when the DOCX is edited and saved. The same placement is used in body text, header/footer bands and table cells. Automatic line spacing measures the text and picture separately, as in Wordcraft, so it does not multiply a tall image's height.

The downloaded docx4j `chunk.docx` example (`docx4j-extra-5aeabaa6f7ce`) formerly misplaced both image and text. It now passes the strict comparison (`inline-picture-focused-result.json`); both pages were visually inspected (`inline-picture-image-inspection.json`). Derived inline-image examples in a table cell and in a header also pass (`inline-table-picture-result.json` and `inline-header-picture-result.json`). The three source fixtures are retained under `crates/edgedoc-display/tests/fixtures/inline-picture`; the original is pinned in the external corpus manifest.
