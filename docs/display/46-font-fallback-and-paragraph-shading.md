# Font fallback and paragraph shading

When a document requests an unavailable font family, the fallback now selects the requested bold and italic variant of the configured fallback family when available. Previously, it always chose the regular fallback face and synthesized the style. Paragraph shading now also extends over a hanging indent, on the appropriate side for the paragraph direction.

The downloaded Apache POI chapter document `poi-extra-797bfdf13936` showed both errors: its bold text used a regular font face, and a shaded empty paragraph began 51.05 points too far right. After both fixes, it passes the strict Wordcraft comparison. The Wordcraft and EdgeDoc page images were inspected; see `fallback-shading-image-inspection.json` and `fallback-shading-focused-result.json`. Eight of ten focused font cases pass; two existing failures remain, and the chapter document is the only status improvement in that subset.

The 181-case regression run (`fallback-181-result.json`) includes all 180 cases passing after the earlier margin and line-break changes and the chapter document. All 181 pass. Workspace tests, Clippy and the rebuilt viewer checks pass (18/18 viewer checks, 134/134 checks over 33 corpus documents). The 394-case report `linebreak-394-streaming-result.json` predates these last two fixes; its 196 failures and 18 blocked cases remain the latest full-corpus measurements, rather than evidence of complete parity.

A separate Symbol-bullet comparison failed under the standard font profile because Wordcraft used the system Symbol font while EdgeDoc was not supplied it. On this machine, supplying `/System/Library/Fonts/Symbol.ttf` to EdgeDoc produced the same font SHA-256 that Wordcraft used, and the case passed (`symbol-font-followup-result.json`); the inspected PNGs are identical. The reference render was retained from the original profile because the comparison adapter cannot extract a Unicode family name from this system font and refuses to register it explicitly. This result depends on the availability and identity of that font; it does not imply that Symbol is bundled or available elsewhere.
